## Recommendation

Checklist winner this run: **`qwen3:0.6b`** (quality 100.0%, mean latency 2.291s, RSS sample 2007.2 MB).

Notes from measured replies:
- Contextual extraction (name/hours/restaurant/availability) is **engine-owned** and identical for both models.
- `qwen3:0.6b` is faster and often near-copies the scripted line (safe, less natural paraphrase).
- `qwen3:1.7b` paraphrases more naturally in French but can leak English meta-reasoning; `server.py` fact-guards reject those replies and fall back to the scripted compose / 0.6B.

**Chosen default configuration:** `OLLAMA_MODEL=qwen3:1.7b` with `OLLAMA_FALLBACK_MODEL=qwen3:0.6b` — naturalness when polish succeeds, deterministic French when it does not. On tight RAM, set `OLLAMA_MODEL=qwen3:0.6b`.
